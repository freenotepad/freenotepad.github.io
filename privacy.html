Privacy Policy

1. Local Client-Side Processing

FreeNotepad operates as a text formatting application prioritizing data isolation. Text compositions entered into the sandbox environment are processed completely inside your device container. Content is structured within the browser configuration utilizing Local Storage boundaries. Your text entries are never transmitted, synchronized, or maintained across external remote computing instances.

2. Analytics & Network Assets

To keep performance optimized, standard technical metrics (such as page view counters, language headers, and layout display properties) are parsed using server network resources. These data packets do not contain individual identification metrics and cannot be linked to the private textual components written into the text workspace environment.

3. Direct Storage Controls

Because your saved text is fully managed inside the local browser application instance, data persistence follows your local device profiles. Clearing your browser data caches, local data footprints, or storage settings will permanently drop current records from the viewport container. Be sure to use the one-click download action to save permanent files directly onto your desktop or mobile systems.

4. Third-Party Integrations

This setup might display contextual banner integrations or scripts to support running layout frameworks. These integrations utilize specialized network logs to monitor asset delivery efficiency without accessing the document editor container.

5. Document Updates

We reserve the right to modify these parameters to meet technical compliance changes. Any modifications to this policy document will be updated on this static layout frame.
